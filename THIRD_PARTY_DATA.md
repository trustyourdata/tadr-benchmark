# Third-party data registry

No third-party datasets are included in this repository.

Before introducing external data, add a reviewed registry entry with dataset
name/version, source, public URL, original license, explicit redistribution
status, citation where applicable, retrieval/version date and checksum where
appropriate. Record any transformations and attribution requirements. Public
download access alone does not authorize redistribution.

The root Apache-2.0 license does not replace third-party data licenses. Generated
benchmark datasets are ignored working artifacts; a future public data release
requires an explicit data-license decision and independent versioning.
